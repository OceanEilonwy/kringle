Kringle

A Kris Kringle / Secret Santa gift swap. A host starts a group, shares one link, adds “never pair” rules, and draws names. Rust + htmx, no accounts.

Features

  • Three kinds of link, no accounts. Admin (host only), invite (shared), personal (one per guest). All unguessable.
  • Wish notes. Optional, editable any time. The giver always sees the latest.
  • Never pair. Rules can be one-way or both ways, with an optional reason (“partners”, “last year”).
  • Live draw check. Every rule change re-checks for a valid draw. If none exists, the Draw button is disabled and the page says why in plain words.
  • Secret by default. Nobody draws themselves. The host sees who has opened their tag, never pairs or anyone’s personal link. Rules that would force a pair block the draw.
  • Cancel & reopen reopens joining; drawing again replaces every tag.
  • One look: Bethlehem. Limestone panels and etched type over a blocky little town under the Star, with a quiet Nativity: the stable, an angel and shepherds.

htmx in use

  • hx-post · hx-target="#rules"Add a rule. The response swaps the rule list and, with hx-swap-oob, the draw status card.
  • hx-trigger="every 5s"The host’s people list and the guest’s waiting page poll a small fragment. When names are drawn, the guest page swaps to the wrapped tag.
  • hx-confirmOn Draw, Cancel draw and Remove person.
  • hx-post="/p/{t}/open"Unwrap swaps the gift box for the tag (swap:300ms for the flip) and records “opened”.
  • hx-boost="true"Forms are real forms. With JS off they post and redirect, so everything still works.

Rust side

  • axum + askama templates: one per page, plus partials that htmx requests return.
  • SQLite (sqlx): groups, members, rules, assignments.
  • Tokens: 128-bit random, base32. Invite links get a friendly prefix (snowy-otter-…).
  • Draw: backtracking search. Givers with the fewest options go first and candidates are shuffled. The search is exhaustive, so “impossible” is a fact, not a guess. Instant for family-sized groups.
  • Styling is one plain CSS file: sky gradient, stone texture from layered gradients, carved and bevel borders, Georgia plus one web font.
