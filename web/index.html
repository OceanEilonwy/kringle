Kris Kringle · Secret Santa

A gift swap that runs on your router

Kringle draws names for your family or friends. Send one link, everyone adds a few gift hints, and each person unwraps their own gift tag. Nobody, not even the host, sees who got who.

Install on your Flint 2 Source on GitHub

How it works

No sign-ups and no app to install. It’s just links, opened in any browser.

Private by design

No accounts, emails or tracking. The data stays on your router in one small file, and old groups are deleted automatically.

Fair and secret

Nobody draws themselves. Rules can’t force a pair, and the host is warned if the group is small enough to guess.

Tiny

One 1.3 MB program with no dependencies. It works without JavaScript and on any phone.

Settings in LuCI

Port, public address and how long to keep groups are all under Services → Kringle in the router’s web interface.

Survives upgrades

Settings and gift swaps are kept across OpenWrt firmware upgrades.

Open source

Written in Rust and licensed under GPL-3.0. Read the code or build it yourself.

Install on your Flint 2

About five minutes. You can do it all from the router’s web interface.

You’ll need

GL.iNet Flint 2 (GL-MT6000) OpenWrt 25.12 with LuCI The router’s root password

This is for stock OpenWrt, not GL.iNet’s own firmware. Other OpenWrt 25.12 routers with an aarch64_cortex-a53 CPU (MediaTek Filogic and similar) work the same way.

In the web interface (LuCI)

  1. 1

    Log in to LuCI

    Open http://192.168.1.1 (your router’s address, if you changed it) and log in as root.

  2. 2

    Trust Kringle’s signing key

    System › Administration › Repo Public Keys tab

    Copy the key below into the box that says “Paste content of a file, or a URL to a key file…”, then click Add key.

    @PUBKEY@

    Or paste this address instead of the key: @PAGES_URL@/kringle.pem

  3. 3

    Add the Kringle repository

    System › Software › Configure apk button

    Find the box for /etc/apk/repositories.d/customfeeds.list. Add this line at the end, on a line of its own, then click Save.

    @PAGES_URL@/@REPO_PATH@/packages.adb
  4. 4

    Install Kringle

    System › Software

    Click Update lists… and wait for it to finish. Type kringle into the Type to filter… box, open the Available tab, and click Install… next to luci-app-kringle. Then confirm with Install. The Kringle server comes with it and starts straight away.

  5. 5

    Open Kringle

    Services › Kringle

    Reload the page first so the new menu item appears. The status line should say Running. Click Open Kringle, or share http://192.168.1.1:8787 with anyone on your Wi-Fi. If it says Not running, tick Enabled and click Save & Apply.

In a terminal (SSH)

  1. 1

    Connect to the router

    From a computer on your network, log in as root. Stock OpenWrt is at 192.168.1.1 unless you changed it.

    ssh root@192.168.1.1
  2. 2

    Trust the key and add the repository

    You only do this once.

    wget -O /etc/apk/keys/kringle.pem @PAGES_URL@/kringle.pem
echo "@PAGES_URL@/@REPO_PATH@/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
  3. 3

    Install Kringle

    This installs the server and its settings page in LuCI. It starts straight away.

    apk update
apk add luci-app-kringle
  4. 4

    Open Kringle

    Go to http://192.168.1.1:8787. Settings are in LuCI under Services › Kringle. If it isn’t running:

    service kringle enable
service kringle start

Optional: let family outside your home join

Network › Firewall › Traffic Rules tab › Add

Name it Kringle. Set Protocol TCP, Source zone wan, Destination zone Device (input), Destination port 8787, and Action accept. Click Save, then Save & Apply. If another router sits in front of the Flint 2, forward the port there too.

Services › Kringle

Set Public address to the address people use from outside (for example http://gifts.example.com:8787), so the links Kringle hands out work from anywhere.

Kringle’s links are the only keys to each group. If it’s reachable from the internet, put it behind HTTPS (a reverse proxy with a certificate) so the links can’t be read in transit.

Updating

System › Software: click Update lists…, then look in the Updates tab. Or in a terminal:

apk update && apk upgrade kringle luci-app-kringle

Settings and gift swaps are kept. After a firmware upgrade, repeat the steps above to reinstall.

Removing

System › Software: in the Installed tab, click Remove… on luci-app-kringle, then kringle. Or in a terminal:

apk del luci-app-kringle kringle
rm -rf /etc/kringle   # also delete all gift swaps

Package files

You don’t need these if you use the repository above. They’re for installing by hand with apk add --allow-untrusted.

    @FILES@
  • packages.adb: the signed repository index
  • kringle.pem: the signing key
