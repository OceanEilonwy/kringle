Kris Kringle · Secret Santa

A gift swap that runs on your router

Kringle draws names for your family or friends. Send one link, everyone adds a few gift hints, and each person unwraps their own gift tag. Nobody, not even the host, sees who got who.

Install on your Flint 2 Source on GitHub

How it works

No sign-ups and no app to install. It’s just links, opened in any browser.

Private by design

No accounts, emails or tracking. The data stays on your router in one small file, and old groups are deleted automatically.

Fair and secret

Nobody draws themselves. Rules can’t force a pair, and the host is warned if the group is small enough to guess.

Tiny

One 1.3 MB program with no dependencies. It works without JavaScript and on any phone.

Settings in LuCI

Port, public address and how long to keep groups are all under Services → Kringle in the router’s web interface.

Survives upgrades

Settings and gift swaps are kept across OpenWrt firmware upgrades.

Open source

Written in Rust and licensed under GPL-3.0. Read the code or build it yourself.

Install on your Flint 2

About five minutes, from a computer on your home network.

You’ll need

GL.iNet Flint 2 (GL-MT6000) OpenWrt 25.12 SSH access as root

This is for stock OpenWrt, not GL.iNet’s own firmware. Other OpenWrt 25.12 routers with an aarch64_cortex-a53 CPU (MediaTek Filogic and similar) work the same way.

  1. 1

    Connect to the router

    Open a terminal and log in. Stock OpenWrt is at 192.168.1.1 unless you changed it.

    ssh root@192.168.1.1
  2. 2

    Add the Kringle package repository

    This trusts the key the packages are signed with, then tells the package manager where to find them. You only do this once.

    wget -O /etc/apk/keys/kringle.pem @PAGES_URL@/kringle.pem
echo "@PAGES_URL@/@REPO_PATH@/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
  3. 3

    Install Kringle

    This installs the Kringle server and its settings page in LuCI. It starts straight away.

    apk update
apk add luci-app-kringle
  4. 4

    Open it

    In LuCI (the router’s web interface), go to Services → Kringle. The status line shows it’s running and has an Open Kringle link. By default that’s http://192.168.1.1:8787, and anyone on your Wi-Fi can use it.

    If it says Not running, tick Enabled and click Save & Apply.

  5. 5

    Optional: let family outside your home join

    Allow the port through the firewall. In LuCI, go to Network → Firewall → Traffic Rules → Add. Set Protocol TCP, Source zone wan, Destination zone Device (input), Destination port 8787, and Action accept. If another router sits in front of the Flint 2, forward the port there too.

    Then set Public address in Services → Kringle (for example http://gifts.example.com:8787), so the links Kringle hands out work from anywhere.

    Kringle’s links are the only keys to each group. If it’s reachable from the internet, put it behind HTTPS (a reverse proxy with a certificate) so the links can’t be read in transit.

Updating

apk update && apk upgrade kringle luci-app-kringle

Or use LuCI → System → Software. Settings and gift swaps are kept. After a firmware upgrade, repeat steps 2 and 3.

Removing

apk del luci-app-kringle kringle
rm -rf /etc/kringle   # also delete all gift swaps

Package files

You don’t need these if you use the repository above. They’re for installing by hand with apk add --allow-untrusted.

    @FILES@
  • packages.adb: the signed repository index
  • kringle.pem: the signing key
